# Blockbound

A small, browser-playable block sandbox inspired by creative building games. No downloads, frameworks, or extra assets are needed.

## Play

Open `index.html` in a modern web browser.

- **Move:** A / D or the left and right arrow keys
- **Jump:** Space, W, or the up arrow
- **Mine:** Click a block near your character
- **Build:** Right-click an empty spot near your character
- **Choose a block:** Click a hotbar slot or press 1–5
- **Start over:** Choose **New world**

The world is randomly generated each time you start a new one. Mined blocks are added to your inventory; use them to build wherever you like.
